# MedSkills - Фронтенд для приложения спортивного врачевания

## 📋 О проекте

**MedSkills** — это веб-приложение для спортивных врачей, разработанное в рамках производственной практики. Приложение предоставляет платформу для тестирования знаний в области спортивной медицины.

### 🎯 Задание на практику

> Создание фронтенда для приложения спортивного врачевания с использованием Vue.js (Nuxt)

## ✨ Функциональность

### 🔐 Аутентификация и авторизация

- Вход в систему по email и паролю
- Регистрация нового пользователя с указанием ФИО, email и пароля
- Восстановление пароля — сброс до стандартного значения `111111`
- **Резервный аккаунт администратора:**
  - Email: `admin@test.ru`
  - Пароль: `admin`
  - Роль: Администратор
- Все остальные зарегистрированные пользователи получают роль «Медицинский работник»
- Middleware для защиты маршрутов — неавторизованные пользователи перенаправляются на страницу входа
- Выход из системы с подтверждением

### 👤 Профиль пользователя

- Просмотр личных данных (ФИО, email, телефон, дата рождения, стаж работы, роль)
- Редактирование профиля через модальное окно
- Автоматическое заполнение роли в зависимости от типа аккаунта
- Синхронизация данных профиля с данными авторизованного пользователя
- Отображение краткого имени в шапке приложения

### 📝 Тестирование

- **4 категории тестов:**
  - 🦴 Травматология спортивная
  - ❤️ Спортивная кардиология
  - 🏋️ Реабилитация после травм
  - 🥗 Питание спортсменов
- **12 тестов** (по 3 в каждой категории)
- Сохранение прогресса тестирования
- Возможность продолжить незавершённый тест
- Навигация между вопросами (вперёд/назад)
- Отображение прогресса прохождения теста
- Подсчёт и отображение результатов после завершения
- Визуальная оценка результата (отлично/хорошо/средне/плохо)
- Возможность повторного прохождения теста

### 📊 Статистика

- Общая статистика по всем тестам (всего, завершено, средний балл, общее время)
- Статистика по категориям с прогресс-барами
- Отображение последних результатов с цветовой индикацией
- Процент выполнения и средний балл по категориям

### 📚 База знаний

- 5 статей по спортивной медицине
- Фильтрация по категориям (травматология, кардиология, реабилитация, питание)
- Поиск по статьям
- Популярные статьи (сортировка по просмотрам)
- Модальное окно с полным содержанием статьи
- Отображение даты публикации и количества просмотров

### ⚙️ Настройки

- Включение/отключение уведомлений
- Выбор языка интерфейса (8 языков)
- Переключение тёмной/светлой темы
- Сброс пароля текущего пользователя до `111111`
- Сброс всех локальных данных с подтверждением

### 🔔 Уведомления

### 🆘 Помощь

## 🚀 Запуск проекта

### Предварительные требования

- **Node.js** версии 20.19.0 или выше (рекомендуется 22.12.0+)
- **npm** или **yarn**

### Установка и запуск

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/TWOKIIII/medskills-frontend.git

# 2. Перейдите в папку проекта
cd medskills-frontend

# 3. Установите зависимости
npm install

# 4. Запустите проект в режиме разработки
npm run dev

# 5. Откройте браузер и перейдите по адресу
# http://localhost:3000

# 6. Данные для входа
# При первом запуске вы можете:
#   • Зарегистрировать новый аккаунт — нажмите «Регистрация» на странице входа
#   • Использовать резервный аккаунт администратора:
#     - Email: admin@test.ru
#     - Пароль: admin
```
